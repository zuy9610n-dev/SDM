# sdm5:Al–Si–Ti–Fe–Cu 5元系探索のための計算支援

`上位文書.md`(v0.2)と、そこに収録された E-1・D・E-2・形B の各設計書 v0.2 を実装したものです。実装の前に設計を検討し直し、**v0.2.1 修正メモ**としてまとめました(`上位文書.md` の冒頭と、詳しい根拠は `docs/設計レビュー_v0.2.1.md`)。

> 直下の `E-1 設計書.md`、`D 設計書.md`、`E-2 設計書.md`、`形B 設計書.md` は v0.1 です。正本は `上位文書.md` の中にある v0.2 と、v0.2.1 修正メモです。

## 構成

| パッケージ | 内容 | 設計書との対応 |
|---|---|---|
| `sdm5.common` | 組成(at%)、区画と cell_id、表のスキーマ、版の固定保存、パラメータ | 上位 3章、修正メモ 1・5 |
| `sdm5.e1` | 固相線の探索、到達可能集合 S、T_max と状態、信頼度、e1_ok、GE1、単相マスク、T_ad | E-1 C1〜C5、修正メモ 6・7 |
| `sdm5.d` | 充填(RSA とラゲール分割)、レベル0、レベル1a(FFT)、EDS の模擬、λ・カバー率、包囲判定、GD2、ラテン超方格によるふるい分け | D 3・5・6・7章、修正メモ 8 |
| `sdm5.e2` | 同じ計算手法だけで作る凸包、P2 の信頼性、P4 の暫定階層と P5 への選別、P6 の配置エントロピー、P7 の正式な階層 | E-2 P1〜P7、修正メモ 2・4・9 |
| `sdm5.formb` | 組成点の列挙、学習データの整形、特徴量(リーク対策つき)、M1・M2(PU バギング)・経験則、元素数ごとのパーセンタイル、G2 の検証 | 形B B1〜B5、修正メモ 3 |
| `sdm5.integrate` | E-2 の照合、段階1〜3、P3b への受け渡し、実験結果の分類 | 上位 4・6章、修正メモ 10 |

仮の値は、すべて `src/sdm5/data/params.yaml` にまとめました(`--params` で上書きできます)。参照データの雛形も同じ場所にあります(`known_phases_seed.csv`、`c4a_diffusion_template.csv`、`db_evaluation_template.csv`)。**どれも未検証なので(verified=False)、文献で確認してから使ってください。**

## 使い方

```bash
pip install -e ".[dev]"            # 必要に応じて [calphad] [mp] [ml]
pytest                              # 全テスト
sdm5 cells  --out out               # 区画表(5 at% 10,626 区画 + 2.5 at% 細分区画)
sdm5 points --out out               # 形B の組成点表(cell_id つき)
sdm5 level0 --d50 20 --L 1,5,10,20  # レベル0の f_k(L)
sdm5 ge1 --L 10 --D c4a.csv         # GE1(C4a の拡散係数の範囲から)
sdm5 tmax --cells cells_with_solidus.csv --powders "100,0,0,0,0;0,100,0,0,0;0,0,100,0,0;0,0,0,100,0;0,0,0,0,100"
```

固相線は、`e1.backends.PycalphadBackend`(C1 で検証済みの TDB)で計算するか、Thermo-Calc などで外部計算した表を `TableBackend` で取り込みます。`e1.toy.ToyBackend` はテスト用の合成データで、物理的に正しい値ではありません。

## 第1段階(1〜3週)で回せるもの
- E-1:C0 の評価表の雛形、C2 の固相線表(TDB が用意でき次第)、C4a の表から GE1 を判定
- D:レベル0(ノートPCで計算可能)、既存試料の EDS 点群から元素数ヒストグラムを作り GD2 の準備
- E-2:P0 の既知相の参照表(雛形あり)、P1 の凸包(mp-api)
- 形B:B1 の学習データの整形
