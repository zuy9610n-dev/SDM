## 2. 上位文書「修正が必要な箇所」の4点(必須)

### R1 データ表の列定義(表の粒度)
- v0.2 の区画表は「1行=1区画」ですが、`e1_phases` は温度(T_anneal ±50 K)、`d_expected_points` は試料設計、`surrounded` は試料ごとに値が変わります。1行=1区画のままでは値を持てません。
- **修正**:区画の表を次の4つに分けます(長形式)。
  - `cells`(区画のマスタ):cell_id, parent_cell_id, resolution, 中心組成, n_elements, e1_solidus, e1_solidus_flag, e1_confidence
  - `cell_phases`(区画×温度):cell_id, T_K, e1_phases, e1_single_phase
  - `cell_design`(区画×試料設計):cell_id, design_id, d_expected_points, n_points_planned, model_version
  - `cell_sample`(区画×試料):cell_id, sample_id, surrounded, n_near
- 5 at% 区画と 2.5 at% 細分区画は、`resolution` 列で分けたうえで同じ `cells` に入れます。細分区画は必ず `parent_cell_id` を持ちます。
- 組成点表では、`e1_ok`、`d_coverage_ok`、照合の距離(`e2_match_d`、`d_nearest`)、判定に使ったしきい値(`match_threshold_at`)を、それぞれ別の列にします。

### R2 E-2 の凸包は同じ計算手法で作る
- `method` タグ(例:`uMLIP:CHGNet`、`DFT:PBE-MP2020`、`DB:MP-GGA_GGA+U`)の異なるエントリが混ざったら、凸包を作る関数がエラーにします。
- 系に含まれる各元素について、同じ手法による単体の参照エネルギーがなければエラーにします。
- E_hull は構造表の中で、手法ごとの列(`ehull__<method>`)に分けて保持します。

### R3 形B のパーセンタイルは元素数ごとに計算する
- `b_percentile` は、同じ元素数(2・3・4・5)の組成点の集団の中での順位にします。部分系ごとの順位は、補助の列 `b_percentile_chemsys` として残します。
- 部分系ごとの順位だと、系ごとに必ず「上位10%」ができてしまい、系どうしを比べられないためです。

### R4 E-2 の P4 の通過しきい値を A 区分に揃える
- v0.2 では、P5 に進めるのは両モデルとも ≤ 50 meV のもの、暫定A は両モデルとも ≤ 70 meV のものでした。このため、50〜70 meV の暫定A は DFT で検証されず、正式な A になる道がありません。
- **修正**:P5 に進める条件の上限を、A 区分の上限に連動させます(`p5_both_max = tier_A_max = 70 meV`)。どちらかのモデルで ≤ 25 meV かつ狙い組成領域にあるもの、という条件は残します。件数が多すぎる場合は、狙い領域を優先して絞ります。

## 3. 追加で見つけた問題

### 共通(組成と区画)
- **R6(必須)区画の丸めでタイが決まらない**:2.5 at% の格子点の半数は、5 at% 区画どうしの境界の上にあります。`np.argsort` の既定(quicksort)は安定なソートではないため、親区画が実行ごとに変わりえます。→ `kind="stable"` を使い、剰余が同じときは元素順で前の元素を切り上げる、と定めます。
- **R7(必須)合計が100でない入力**:EDS の値は合計が 99.x などになり、`n - base.sum()` がずれます。→ 負の値は0にし、合計100に規格化してから丸めます。
- **R8(必須)包囲判定の線形計画が解けない**:5成分とも等式に入れると、合計の行が冗長になり、測定点に誤差があると解がなくなります。→ 最後の成分を落として4成分で判定し、点は規格化してから使います。

### E-1
- **R9(必須)固相線のコードの不具合**:(a)「液相なし」のときに t_hi をそのまま固相線として返しており、下限の値であることが区別できません。→ フラグ `上限まで液相なし` を加え、4つの値にします。(b)細かい刻みの探索で液相が見つからないと、`argmax` が 0 を返し `fine[-1]` になります。→ ガードを入れます。
- **R10(必須)e1_ok の条件が空回りする**:T_anneal ≤ T_max = min_S(固相線) − ΔT_safe なので、S の中にある区画は「e1_solidus ≥ T_anneal + ΔT_safe」を自動的に満たします。→ 設計単位の条件 `T_anneal ≤ e1_T_max` を明示的に加えます。区画の `e1_solidus_flag` が `非単調` なら「要DSC確認」、`下限で液相あり` なら「不可」とします。
- **R11(推奨)e1_T_max_status**:最小値をとる区画だけを見ると、信頼度が低く、最小値にわずかに届かない区画を見落とします。→ 信頼度が低い区画の固相線が「最小値 + ΔT_low(仮に 50 K)」以内にあれば、「要DSC確認」とします。
- **R12(必須)拡散距離 L が定義されていない**:GE1 は「L に届くか」を判定しますが、L と D·t の関係が文書に書かれていません。→ L = 2√(D t) と定め、必要な時間を t_req = L²/(4D) とします。GE1 は、C4a の範囲の上限と下限を使って3つの値で判定します(可:遅い側の値でも ≤ 300 h/不確定/不可:速い側の値でも > 300 h)。
- **R22(推奨)T_anneal を渡す時期の矛盾**:E-2 に T_anneal を渡すのは8週ですが、試料設計が決まるのは12〜13週です。→ 8週には暫定値(主な設計候補の T_max の集合)を渡し、P6 はその集合で評価します。設計が決まったら確定値で計算し直します。
- **R28(推奨)T_ad**:Cp のデータがないときは Dulong–Petit の近似(3R/mol-atom)を使います。融解熱を無視するので T_ad は高めに出ます(安全側)。

### D
- **R13(必須)ランダム逐次配置の充填率の上限**:ランダム逐次配置(RSA)で得られる充填率は、3次元では約38%が上限です。圧粉体(60%以上)や焼結体(90%以上)とは大きく違います。→ RSA で置いた粒子の中心と半径から、ラゲール分割(パワー図)で空間を埋め、緻密な圧粉体の近似にします。レベル0と1a の初期配置に共通で使います。実際の体積分率は計算して報告します。
- **R14(必須)λ の基準**:λ は予定の測定点数 N に比例します。→ 試料設計表と `cell_design` に N(`n_points_planned`)を記録します。`d_coverage_ok` は 5 at% の区画の λ で判定します。細分区画の λ は体積の比でおよそ1/16になり、基準の意味が変わるためです。
- **R15(推奨)単相マスクで補正したカバー率**:C_k^mask =(覆われた単相区画の数)/(k元素の単相区画の数)と定義します。

### E-2
- **R16(必須)正式な階層に抜けがある**:(a)E_hull ≤ 25 で部分系の信頼度が「中」の候補は、S の条件(信頼度が高)も A の条件(25〜70)も満たさず、どこにも入りません。→ A とします。(b)信頼度の高・中の境界が決まっていません。→ 再現率 ≥ 0.9 を高、0.7〜0.9 を中、< 0.7 を低とします(仮)。(c)既知化合物のない部分系(Al–Si、Cu–Fe)では再現率が計算できません。→ 誤安定が0件なら高、1件以上なら中とします。(d)4元系以上の候補の信頼度は、構成するすべての部分系の信頼度の最小値とします。
- **R17(推奨)「2モデルが大きく食い違う」**:|ΔE_hull| > 50 meV/atom(仮)と定義します。
- **R26(推奨)A の「安定化の見込み」**:E_hull − T·S_conf(原子あたり)− ΔF_vib ≤ 25 meV/atom と定義します。

### 統合
- **R18(必須)E-2 で保留の候補の扱い**:E-2 で「保留」の候補は S・A ではないので、v0.2 の表では「不安定」の列に入り、形B のスコアが高いと③として P3b に送られます。すでに構造があるのに、構造探索に回ってしまいます。→ E-2 で保留の候補は、形B に関係なく最終優先度を「保留」にします。
- **R19(推奨)②の磁気確認**:本統合の「優先」には「P5 で磁気配置を確認済み」が必要ですが、確認していない②の行き先が決まっていません。→ 保留とします。Fe を含まない候補は、確認不要とみなします。
- **R20(推奨)段階2の合成の規則**:e1_ok と d_coverage_ok を合わせるときは、「不可」を最優先し、次に「要DSC確認」、両方が「可」のときだけ「可」とします。
- **R21(推奨)G2 を通過しなかった場合**:E-2 で安定なら①と同じ規則で扱い(記号は「E2単独」)、不安定なら④とします。③は生じません。
- **R23(推奨)G2 の「はっきり上回る」**:recall@10% の差をブートストラップで評価し、95% 信頼区間の下限が0より大きいことを条件にします(時系列分割と元素数の外挿の両方で)。
- **R29(推奨)6章の新相候補**:照合できない点の集まりのうち、XRD・EBSD による確認がまだのものは「判定不能(構造確認待ち)」とします。

### 形B
- **R24(確認)**:形B の組成点(原子数 ≤ 20 の整数比)と D の区画(5 at% の格子)は別の格子です。cell_id は `to_cell` で付けるので、両者は矛盾しません。
